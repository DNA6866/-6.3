==========================================================
NVIDIA 显卡硬件加速（NVENC）开启指引
适用：混剪时提示"ffmpeg 返回码 -40 / h264_nvenc 打不开"、输出目录为空
==========================================================

一、你的显卡是否支持硬件加速
----------------------------------------------------------
NVIDIA Quadro / GeForce / RTX 系列都支持 NVENC 硬件编码。
例如：Quadro P620、GTX 1050+、RTX 20/30/40 系列都可以。

二、先判断是不是"远程桌面"在用（最常见原因）
----------------------------------------------------------
如果你的软件是通过 远程桌面 / 云电脑 / 向日葵远程 操作的，
Windows 会禁用显卡硬件加速，装驱动也没用。

判断方法：
  1. 看电脑屏幕左上角是否有"连接进度"或黄色条
  2. 是否经常通过 手机/另一台电脑 控制这台电脑
  3. 开始菜单搜索"远程桌面设置"，看是否开启"远程桌面"

如果是远程桌面使用，请在电脑本地（人坐在电脑前）运行软件，
NVENC 即可正常使用。

三、安装/更新显卡驱动（非远程桌面时）
----------------------------------------------------------
1. 打开浏览器访问 NVIDIA 驱动下载页：
   https://www.nvidia.cn/drivers/

2. 选择型号：
   - 产品类型：NVIDIA RTX / Quadro
   - 产品系列：Quadro P 系列
   - 产品：Quadro P620
   - 操作系统：Windows 10 64-bit
   - 点击"搜索" → 下载最新驱动（约 700MB）

3. 双击下载的驱动安装，一路下一步，安装完成后重启电脑。

4. 重启后验证：右键桌面空白处 → NVIDIA 控制面板 →
   左上角"帮助" → "系统信息" → 确认驱动版本已更新。

四、如果还是不行
----------------------------------------------------------
本软件已内置"自动回退 CPU"机制：当检测到硬件编码不可用时，
会自动改用 CPU 编码，保证能出片（只是比显卡慢一些）。
不会再次出现"任务完成但输出目录为空"。

如果以上都试过仍想提速，建议：
- 增加内存到 16GB 以上（当前 16GB 已够用）
- 换一张显存更大的显卡（如 RTX 3060 12GB），速度提升明显
- 或确认非远程桌面环境后重试

==========================================================
如仍有问题，请反馈：
1. 软件"批量混剪 → 性能检测"里的详情文字
2. 是否远程桌面使用
3. 驱动版本号
