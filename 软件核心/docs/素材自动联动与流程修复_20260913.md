# 素材自动联动与流程修复

## 模板与目录

- 模板保存目录、参数和选择方式。全选模式不再保存几百条重复文件路径。
- 空闲时每两分钟后台核对当前模板素材目录；增删素材自动更新列表。
- 点击开始任务、预览样片或加入新队列，会再次后台核对实际目录后继续。
- 每日自动计划仍在当日建立任务时读取最新目录，并按各店铺目标重新计算轮数。
- 全选包含新增文件，手动部分勾选只保留仍存在的已选文件，不擅自全选新文件。
- 从全选列表单独取消一项，会退出全选模式但保留其他选中项，刷新不再选回被取消项。
- 同一目录的素材选择自动同步回模板；未保存的其他参数、新目录不会被顺带写回。
- 自动同步配置写入失败时记录明确提示，回滚内存选择以便下次重试，不让异常逃逸到界面线程。
- 已经入队或运行的任务保留当时快照及断点，不因模板刷新改变任务数量。
- 因此不要删除尚在排队或运行的任务所需素材；这类旧任务不会自动换成新素材。
- 目录缺失、NAS子目录读取失败时不使用不完整列表启动新任务，也不重建失效目录。
- 核对期间停止、关闭软件或切换模板/目录，不会随后误启动原来的提交。

## 其他已确认修复

- 导入不同子目录的同名素材不再覆盖：自动附加序号，原文件保留。
- 音视频处理同一批次、同一秒的同名输入，分别生成唯一输出路径。
- 音视频处理单个文件失败后继续后续文件，准确报告成功及失败数量。
- 音视频子功能串联仅使用本次成功文件，清除前次任务残留输出引用。
- 时长探测增加超时，避免损坏文件使探测无限等待。
- 快速剪辑切换预览未完成时，不能把当前视频的入出点写入另一视频片段。
- 快速剪辑停止导出后，显示已停止和未完成数量，不虚报100%完成。
- 公平轮转任务没有新增产出时保留断点并标记失败，不无限自动重排。
- 手动刷新音频列表改变行号后，运行进度按源文件对应，不写错音频行。

## 代码位置

- `modules/batch_mixer/asset_refresh_mixin.py`：新任务核对、取消和模板选择同步。
- `modules/batch_mixer/asset_mixin.py`、`ui_components.py`：真实扫描、选择保留和进度对应。
- `modules/batch_mixer/project_queue_mixin.py`：入队前刷新、一次性恢复选择、无进展处理。
- `modules/batch_mixer/task_mixin.py`、`daily_automation_mixin.py`：手动与自动任务协调。
- `services/batch_project_service.py`：仅持久化同目录素材选择，不更改队列快照。
- `services/media_service.py`：同名素材安全导入。
- `modules/av_processing/page_mixin.py`、`workers.py`：输出命名、超时、逐文件容错。
- `modules/quick_video_trim/quick_video_trim_widget.py`：跨视频选区保护及取消状态。
- `ui.py`：停止任务时取消未完成的素材核对和每日准备。
