# 牛爷爷工具箱项目记忆树

更新时间：2026-06-28

## 1. 稳定基线

- `611稳定版`是经典批量混剪的可恢复基线。
- 还原点位于：`用户工作区/版本还原点/611稳定版`。
- 经典混剪必须保持可生产，实验功能不得直接替换稳定引擎。
- 当前源码存在用户持续开发改动，禁止为单项需求回退其他模块。

## 2. 目录与发布原则

- `软件核心`：程序源码、模块、脚本和说明文档。
- `用户工作区`：客户素材、配置、日志、缓存、输出和版本还原点。
- `网盘资源包`：FFmpeg、ComfyUI、模型等大型共享依赖。
- 只要涉及功能、UI或客户可见行为改动，不自动生成覆盖包；只有用户明确要求“生成覆盖包/打包/发客户”时才执行。
- 用户明确要求生成覆盖包时，必须生成一个累计完整客户覆盖包，包含此前所有已确认更新，不做单项增量包，确保客户只收一个包也能更新到最新状态。
- 纯讨论、方案确认、日志排查且未改动代码或配置时，不生成客户覆盖包。
- 用户要求发布时，优先生成一个可直接拖入软件目录执行的离线更新包。
- 客户版本可能不一致，更新器负责定位软件目录、备份并覆盖更新文件。

## 3. 经典批量混剪

### 已有主模式

- 传统音频混剪：音频决定总时长，视频素材随机拼接。
- 数字人口播第一轨道：第一轨道提供原声和总时长，产品素材按设置覆盖。
- 强结构：钩子后按数字人、产品交替，后半段由产品素材接管。

### AI完整开场模式

- 输出数量仍由第一轨道数量乘以执行轮次决定。
- 每条成片先完整播放一个AI开场视频，再进入原第一轨道混剪结构。
- AI视频不裁剪时长、不变速、不做随机缩放动画、不叠加水印和字幕；仅按成片画幅做必要的比例适配。
- AI视频保留原声；无音轨时自动补充等长静音。
- 多个AI视频采用均衡随机循环，使用次数差最多为1。
- AI完整开场模式下，已勾选的钩子素材自动忽略。
- AI开场结束后，数字人露出、产品穿插、后段接管、转场、缩放和防重等原设置继续生效。
- 字幕仅对应第一轨道内容，时间轴自动后移AI视频和封面时长。
- AI素材缺失或处理失败时停止当前任务，不静默输出缺少AI开场的降级成片。

## 4. 混剪实验室 V2

### 当前代码状态

- V2位于：`软件核心/modules/mixer_v2`。
- 当前实现仍是音频驱动的随机素材拼接实验版。
- V2使用独立配置、缓存和输出目录，不修改经典混剪引擎。
- 当前V2不得作为正式客户生产流程发布。

### 已确认的重构方向

- 同行视频作为“结构模板”，不是普通素材。
- 智能切割同行视频，记录每个镜头槽位的顺序和原始时长。
- 结构保存为软件自己的JSON，不把剪映草稿作为核心依赖。
- 软件直接完成替换、渲染、暂停、续做和质检。
- 剪映草稿以后可以作为可选导出功能。
- 多条同行模板共用一套分类素材库，不为每个模板复制大量实体文件夹。
- 支持通用随机、人工分类匹配和后续智能画面匹配。
- 短手机素材通常是一镜到底，短于约8秒时优先视为完整镜头，不强制二次切分。

## 5. 稳定性规则

- 长任务必须支持安全停止，并等待工作线程和FFmpeg子进程结束。
- 禁止在线程仍运行时销毁`QThread`。
- 网络第一轨道需要支持子目录扫描和必要的本地暂存。
- FFmpeg硬件编码异常时允许CPU兜底，但不能悄悄丢失关键结构。
- 关键素材缺失、AI开场失败或输出质检失败时必须写明确日志。
- UI数字输入框应支持键盘直接输入，并避免鼠标滚轮误切换下拉选项。
- 文字水印界面以`611稳定版`的布局为回退基线；此前单独增加最小高度的方案在客户环境无效，后续不得继续沿用该方向硬改。

## 6. UI与交互记忆

### 批量混剪：文字水印 / 智能字幕

- 文字水印和智能字幕的右侧`核心参数`必须与其他子功能区保持同一套宽度，不要为了给预览让空间而单独压缩核心参数区。
- 预览区要优先完整显示9:16画面，不能裁切底部；沙盘区域发生尺寸变化后，预览画布必须重新计算尺寸。
- `水印沙盘/字幕沙盘`里的按钮行应保持紧凑并靠上，预览画面也应靠上显示，避免下方被遮挡。
- 不要只放大沙盘外框而让内部画面保持小尺寸；用户关心的是内部真实预览画面尽量吃满可用红框区域。
- 文字水印的`9:16 卖点随机池`应放在左侧竖栏，保持客户一眼能看到；不要把它放到参数区下方导致需要滚动才发现。
- 文字水印参数区中，`固定文字`输入框需要保留较大空间；字体、颜色、对齐、描边、坐标、动画等普通输入/选择控件不应铺满整行，应使用紧凑宽度。
- `商业矩阵水印预设库`需要放在水印列表表格上方，首屏尽量可见，避免客户不知道还有预设功能。
- 修改UI时必须先保证现有结构不被破坏，不用“压缩左边/压缩右边”来换单个区域的放大；如需变大，优先调整当前区域内部布局和尺寸重算逻辑。

## 7. 老版本升级规则

- 客户覆盖包必须使用当前源码重新构建；文件夹名称“客户覆盖包”不代表其内容自动为最新版。
- `一键更新.exe`按完整基线方式替换主程序和`软件核心依赖`，保留客户的`用户工作区`与`网盘资源包`。
- 普通老版本应运行一键更新器并选择包含主程序EXE的安装根目录，不能只复制包内某一个零散文件。
- 如果版本过老导致更新器无法识别，采用干净迁移：备份`用户工作区`和`网盘资源包`，部署全新程序目录，再放回这两个目录。
- 不让客户把新旧`软件核心依赖`内容手工混合，否则可能出现新EXE搭配旧界面的情况。

## 8. 后续优先级

1. 保持经典混剪稳定并完成真实客户素材验证。
2. 继续观察AI完整开场在10秒、15秒及批量长任务下的内存和速度。
3. 按“同行结构模板 + 共享素材库”重构V2，不继续扩展当前音频随机方案。
4. V2验证稳定后再决定是否进入客户覆盖包。
